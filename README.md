# 🌾 AgroSphere (e035800e)

## 🚀 Project Overview
AgroSphere solves resource mismanagement in traditional farming by integrating real-time agricultural data streams with eco-conscious automation. Powered entirely by sustainable solar energy, the system reduces water and chemical waste while maximizing crop yields through data-driven precision analytics.

### 🌟 Key Features
*   💧 **Smart Irrigation:** Automated water delivery based on real-time soil moisture thresholds to prevent over-flooding.
*   📊 **Soil & Nutrient Monitoring:** Continuous physical tracking of NPK levels (Nitrogen, Phosphorus, Potassium) and soil conductivity.
*   🧪 **Fertilizer Optimization:** Machine-driven dosage calculations to minimize chemical runoff and protect soil biomes.
*   ☀️ **Solar Energy Analytics:** Clean energy monitoring that tracks battery health and solar generation efficiency.
*   📸 **Crop Health AI:** Computer vision framework to detect early-stage crop diseases and leaf anomalies.

---
## 🛠️ Architecture & Tech Stack
*   **Backend & Simulation:** Python (FastAPI / Flask)
*   **Database:** PostgreSQL / TimescaleDB (Time-series optimization)
*   **Frontend UI:** Streamlit / Flutter (Farmer Accessibility App)
*   **AI Engine:** TensorFlow Lite (Edge disease detection)
